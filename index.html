Forbind til GitHub

Appen læser din formue fra det private repo nvrkp/net-worth. Den skal bruge en nøgle, der kun kan læse det repo og starte en opdatering. Nøglen gemmes kun på denne telefon.

  1. Tryk Lav nøgle på GitHub og log ind som nvrkp.
  2. Repository access: Only select repositories → net-worth.
  3. Permissions: Actions: Read and write. Contents: Read-only.
  4. Udløb: længst muligt. Tryk Generate token og kopiér den.
  5. Kom tilbage hertil og indsæt den.

Åbn siden fra ikonet på hjemmeskærmen, før du indsætter nøglen. Safari og hjemmeskærmsappen gemmer hver for sig.
